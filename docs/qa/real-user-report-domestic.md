หมายเหตุก่อนอ่าน: หน้าล็อกอินไม่มีช่องให้พิมพ์ชื่อ "แม่ติ๋ม" มีแต่ปุ่ม LINE / Google กดแล้วถูกพาเข้าเป็นคนอื่น (Beam) แล้วระหว่างใช้ชื่อบนจอก็เปลี่ยนเป็น "Mint" เอง (น่าจะเพราะมีคนอื่นใช้เบราว์เซอร์เดียวกันอยู่) แม่เลยใช้ในชื่อ Mint ตลอด และหน้าจอบนมือถือกว้างกว่าที่ตั้งใจ (ขนาดจอปรับเป็น iPhone ไม่ได้) นอกจากนี้ทุกหน้าโหลดช้า 3–4 วินาที ตอนกดแล้วจอนิ่งเฉยๆ แม่ต้องกดซ้ำหลายครั้งเพราะไม่แน่ใจว่ากดติดไหม

### เป้าหมาย 1: สร้างทริปหัวหิน 3 วัน แล้วชวนครอบครัว
- ผลลัพธ์: ทำได้แต่ติดขัด (สร้างทริปได้ ชวนครอบครัวไม่สำเร็จ)
- ความง่าย: 3/5
- ทำอะไรไปบ้าง: กด LINE → สร้างทริปใหม่ → พิมพ์ชื่อทริป, ปลายทาง "หัวหิน" → แก้วันกลับให้เป็น 3 วัน → สร้างทริป → จัดการสมาชิก → คัดลอกลิงก์เชิญ
- ตรงที่งง / ติด: วันไป–วันกลับตั้งไว้ให้เป็น 4 วัน แม่ต้องแก้เอง ส่วนการ "ชวนครอบครัว" ไม่มีช่องให้พิมพ์ชื่อสามีกับลูกๆ เลย มีแต่ลิงก์ให้คัดลอกไปส่ง แล้วต้องรอให้แต่ละคนกดเข้ามาเอง และมีสวิตช์ "ต้องอนุมัติก่อนเข้าทริป" ที่แม่ไม่รู้ว่าต้องเปิดไว้ไหม ตอนนี้ทริปจึงมีสมาชิกแค่แม่คนเดียว ("1 คน") (รูป: screenshots/real-user/dom-invite-link.png)
- คำที่ไม่เข้าใจ: "ผู้จัดทริป / แก้ไขได้ / ดูอย่างเดียว" — พอเดาได้ แต่ไม่รู้ว่าจะให้ลูกเป็นแบบไหนดี; "รีเซ็ตลิงก์" — ไม่กล้ากด กลัวทำลิงก์พัง
- ที่ชอบ: หน้าสร้างทริปมีตัวอย่างการ์ดทริปอยู่ด้านบนเปลี่ยนตามที่พิมพ์ เห็นแล้วอุ่นใจ; บอก "3 วัน 2 คืน" ให้ชัด

### เป้าหมาย 2: จดการจองโรงแรม (ชื่อ, วันเข้า–ออก, ราคา, ที่อยู่/แผนที่, เลขจอง)
- ผลลัพธ์: ทำได้แต่ติดขัด
- ความง่าย: 2/5
- ทำอะไรไปบ้าง: แท็บแผน → "+ สถานที่" → "ไม่มีในลิสต์? สร้างสถานที่ใหม่" → พิมพ์ชื่อโรงแรม → เลือกประเภท "ที่พัก" → ปุ่มบันทึกกดไม่ได้ (สีเทา) → เพิ่มเมือง "หัวหิน" ปุ่มถึงกดได้ → บันทึก → ไปกด "ลงแผน" เพื่อวางลงวันที่ 1
- ตรงที่งง / ติด:
  - ไม่มีช่องวันเช็คอิน/เช็คเอาท์ ไม่มีช่องราคา ไม่มีช่องเลขที่จอง ไม่มีช่องที่อยู่ มีแต่ "ลิงก์ Google Maps (ไม่บังคับ)" กับ "โน้ต" แม่เลยพิมพ์ทุกอย่างรวมในโน้ตช่องเดียว (วันที่ ราคา เลขจอง ที่อยู่) (รูป: screenshots/real-user/dom-add-place-form.png)
  - หลังบันทึกแล้ว ไม่เห็นโน้ตที่พิมพ์ไว้ที่ไหนอีกเลย ทั้งในลิสต์สถานที่และในแผน แม่เลยไม่แน่ใจว่าข้อมูลหายหรือเปล่า
  - ปุ่มบันทึกสีเทาโดยไม่บอกว่าขาดอะไร ต้องเดาเองว่าต้องใส่ "เมือง" ทั้งที่แม่พิมพ์ปลายทางหัวหินตอนสร้างทริปแล้ว
  - ประเภทที่ถูกเลือกไว้ให้ตอนแรกคือ "ที่กิน" ไม่ใช่ที่พัก ถ้าไม่ดูดีๆ โรงแรมจะถูกจดเป็นร้านอาหาร
  - ตอนสร้างเสร็จมันไม่พาไปไหนต่อ ต้องไปหาปุ่ม "ลงแผน" เอง (ปุ่มสีส้มเล็กๆ)
- คำที่ไม่เข้าใจ: "ลงแผน" — เดาว่าเอาไปใส่ในตารางแต่ละวัน; "ย่าน", "Tag" — ไม่รู้ว่าต้องใส่ไหม; "ลิสต์" — เดาว่าคือรายการสถานที่ของทริป
- ที่ชอบ: เลือก "ที่พัก" เป็นประเภทได้, ลงแผนแล้วเลือกได้ว่าจะใส่วันไหนบ้าง และเลือกหลายวันได้ (รูป: screenshots/real-user/dom-add-to-plan.png)

### เป้าหมาย 3: พิมพ์วันเช็คเอาท์/ราคาผิด ต้องแก้
- ผลลัพธ์: ทำได้แต่ติดขัด (ราคาแก้ได้ ข้อมูลโรงแรมแก้ไม่ได้)
- ความง่าย: 3/5 (ค่าใช้จ่าย) / ยอมแพ้ (ตัวโรงแรม)
- ทำอะไรไปบ้าง:
  - ที่ตัวโรงแรม: กดชื่อโรงแรมในหน้าสถานที่ 2 ครั้ง กดชื่อในหน้าแผน 1 ครั้ง กดขีด "−" ข้างซ้าย 1 ครั้ง — ไม่มีอะไรเกิดขึ้นเลย ยอมแพ้ (รูป: screenshots/real-user/dom-plan-day1-no-detail.png)
  - ที่ค่าใช้จ่าย: เข้าหน้ารายการค่าใช้จ่าย → กดรายการ → กดรูปดินสอมุมขวาบน → แก้ 5,400 เป็น 5,600 → บันทึก ทำได้
- ตรงที่งง / ติด: แม่หาทางแก้ข้อมูลโรงแรม (ชื่อ, โน้ตที่พิมพ์ผิด) ไม่เจอ กดแล้วเงียบ ไม่รู้ว่ากดผิดที่หรือทำไม่ได้ ส่วนค่าใช้จ่ายแก้ง่าย เจอดินสอเร็ว และมีปุ่ม "ลบรายการนี้" สีแดงอยู่ใกล้ปุ่มกด ทำให้แม่กลัวนิ้วพลาด
- คำที่ไม่เข้าใจ: -
- ที่ชอบ: หน้าแก้ค่าใช้จ่ายใช้ฟอร์มเดิม ตัวเลขใหญ่อ่านง่าย พอบันทึกแล้วกลับไปหน้ารายละเอียดและเห็นยอดใหม่ทันที

### เป้าหมาย 4: เปลี่ยนโรงแรมคืนที่ 2 ให้โชว์ 2 โรงแรม

- คำที่ไม่เข้าใจ: -
- ที่ชอบ: ผลลัพธ์ชัด วัน 1 มีโรงแรมแรก วัน 2 มีโรงแรมที่สอง

### เป้าหมาย 5: จดว่าจ่ายค่าโรงแรมแล้ว หารกัน 4 คน ดูว่าใครต้องโอนเท่าไหร่
- ผลลัพธ์: ยอมแพ้ (จดได้ แต่หารกับครอบครัวไม่ได้)
- ความง่าย: 2/5
- ทำอะไรไปบ้าง: แท็บค่าใช้จ่าย → เพิ่มค่าใช้จ่าย → ใส่ 5400 → ชื่อ "ค่าโรงแรม 2 คืน" → หมวด "ที่พัก" → เลื่อนลงไปดูส่วน "หารกับ" → บันทึก → ดูหน้าสรุป
- ตรงที่งง / ติด: ตรง "หารกับ" มีแค่ชื่อแม่คนเดียว ("1 คน") เพราะสามีกับลูกยังไม่ได้กดลิงก์เข้ามา ไม่มีปุ่มเพิ่มคนที่ไม่ได้ใช้แอป หน้าสรุปจึงขึ้นว่า "ทุกคนเคลียร์ครบแล้ว ไม่มีใครต้องโอน" ซึ่งทำให้แม่งงมาก เพราะแม่เพิ่งจ่ายไป 5,600 บาท (รูป: screenshots/real-user/dom-expense-only-me.png, screenshots/real-user/dom-summary-nobody-owes.png) ส่วนวันที่ของค่าใช้จ่ายถูกตั้งเป็นวันแรกของทริปโดยอัตโนมัติ ทั้งที่ค่าโรงแรมครอบคลุมสองคืน และค่าใช้จ่ายไม่เชื่อมกับโรงแรมที่ลงในแผนเลย (ต้องพิมพ์ชื่อใหม่เอง)
- คำที่ไม่เข้าใจ: "ช่องทางชำระเงิน", "สลิป" เข้าใจ; "เศษสตางค์รวมไว้กับผู้จ่าย" — ไม่แน่ใจว่าหมายถึงอะไร; "เคลียร์" — เข้าใจว่าหมายถึงจ่ายหมดแล้ว
- ที่ชอบ: ปุ่มบันทึกบอกยอด "คนละ ฿5,400" ให้ดูอุ่นใจ, มีหมวด "ที่พัก" ให้เลือก, หน้าสรุปสะอาด อ่านง่าย

### เป้าหมาย 6: ดูแผนแล้วเห็นง่ายไหมว่าคืนไหนนอนที่ไหน
- ผลลัพธ์: ทำได้แต่ติดขัด
- ความง่าย: 3/5
- ทำอะไรไปบ้าง: แท็บแผน → กดวัน 1, 2, 3 สลับดู
- ตรงที่งง / ติด: เห็นว่าวัน 1 มีโรงแรมแรก วัน 2 มีโรงแรมที่สอง แต่ต้องกดสลับทีละวัน ไม่มีหน้าที่เห็น "คืนที่ 1 นอนที่ไหน คืนที่ 2 นอนที่ไหน" รวมกัน ในการ์ดโรงแรมไม่มีวันเข้าพัก/ออก ราคา หรือเลขจอง วัน 3 ว่างเปล่า ไม่บอกว่าเช็คเอาท์ก่อนกลับ และวันที่ 2 โรงแรมแรกไม่ปรากฏ ไม่รู้ว่าเช็คเอาท์เช้าวัน 2 ไหม
- คำที่ไม่เข้าใจ: "ยังไม่จัดวัน / จัดครบทุกที่แล้ว" — พอเข้าใจ
- ที่ชอบ: แท็บวันที่อ่านง่าย บอกวันที่กำกับ (อา. 29, จ. 30, อ. 1)

### 5 อย่างที่อยากให้แก้ที่สุด
1. ชวนครอบครัวไม่ได้ถ้าเขาไม่ได้โหลดแอป: อยากพิมพ์ชื่อสามีกับลูกเข้าไปเลยเพื่อหารเงินได้ (ตอนนี้หารได้แค่กับคนที่กดลิงก์เข้ามาแล้ว และหน้าสรุปบอกว่า "ไม่มีใครต้องโอน" ทั้งที่แม่จ่ายไปคนเดียว)
2. ที่พักไม่มีช่องที่โรงแรมต้องมี: วันเข้าพัก–ออก, ราคา, เลขที่จอง, ที่อยู่ — ตอนนี้ต้องยัดรวมในโน้ต แล้วก็มองไม่เห็นโน้ตนั้นอีก
3. หาทางแก้ข้อมูลโรงแรมที่พิมพ์ผิดไม่เจอ กดชื่อไปมาไม่มีอะไรเกิดขึ้น (ค่าใช้จ่ายแก้ได้ แต่ตัวโรงแรมไม่ได้)
4. อยากเห็นภาพรวมว่า "คืนไหนนอนที่ไหน" ในที่เดียว และเมื่อจ่ายค่าโรงแรมอยากให้ผูกกับโรงแรมนั้นอัตโนมัติแทนที่จะพิมพ์ชื่อซ้ำ
5. ปุ่มบันทึกสีเทาโดยไม่บอกเหตุผล (ต้องใส่เมืองก่อน), ประเภทเริ่มต้นเป็น "ที่กิน", และทุกหน้าโหลดช้ากดแล้วไม่มีอะไรบอกว่ากำลังทำงาน ทำให้แม่กดซ้ำหลายรอบ และหน้าล็อกอินไม่ให้ใช้ชื่อของตัวเอง
