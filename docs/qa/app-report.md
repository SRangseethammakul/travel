### ความเห็นต่อส่วนที่ออกแบบเอง (ไม่มี mockup)

- **สีช็อปปิ้ง (danger-soft / danger-ink):** ตอนนี้ไม่ชนกันในหน้าจอเดียว เพราะช็อปปิ้งมีแค่ในมุมมองส่วนตัว และหัวการ์ดส่วนตัวเป็นสีเข้ม (ink) ไม่มีการ์ดแดง "ค้างจ่าย" แต่สีกุหลาบนี้ใช้ทั้งแอปเพื่อบอกว่า "ค้างเงิน / ลบ" (การ์ด Expenses, Summary "ต้องจ่ายเพิ่ม", ปุ่มลบ) และช็อปปิ้งน่าจะเป็นหมวดที่ใช้บ่อยที่สุดในมุมมองนี้ รายการจึงดูเหมือนคำเตือน **แนะนำ:** เพิ่ม token เฉพาะ (เช่น `--color-shopping-soft` / `-ink`) หรือใช้สีที่ไม่มีความหมาย ไม่ใช่บั๊ก
- **ไอคอนแม่กุญแจ + "เห็นแค่คุณคนเดียว…":** ชัดเจน ขึ้นทั้งใต้จำนวนเงินในฟอร์ม และเหนือรายการ หน้าว่างใช้ข้อความเต็มแทนไอคอน ซึ่งเหมาะแล้ว ข้อความบนรายการ ("ไม่นับรวมในยอดของกลุ่ม") กับในฟอร์ม ("ไม่นำไปหารกับใคร") ต่างกันเล็กน้อย แต่ความหมายตรงกันทั้งคู่ ใช้ได้
- **ค่าเริ่มต้น ช็อปปิ้ง + เงินสด:** เหมาะกับกรณีหลัก (ของฝาก) · วันที่เริ่มต้นเป็นวันแรกของทริปถ้ายังไม่ถึงทริป ใช้ได้ · เงินสดต่างจากฟอร์มกลุ่ม (พร้อมเพย์) ดู APP-12 ถ้าตั้งใจให้ต่างก็ใช้ได้ เพราะของที่ซื้อเองตอนเที่ยวมักจ่ายเงินสด
- **ข้อสังเกตเล็กน้อย:** ช่องวันที่เป็น date input ของเบราว์เซอร์ จึงแสดง 30/01/2027 (ค.ศ.) เหมือนฟอร์มกลุ่ม ไม่ใช่เรื่องเฉพาะฟีเจอร์นี้ · ทุก `invalid_input` ของ backend ได้ข้อความเดียว "ข้อมูลไม่ถูกต้อง" แต่ฟอร์มกันไว้ก่อนแล้ว ผู้ใช้จึงไม่เห็น
