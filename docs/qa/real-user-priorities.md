## ลำดับความสำคัญ

### P0 — ทำเป้าหมายหลักไม่ได้ หรือทำให้เข้าใจผิดเรื่องเงิน/ข้อมูล
1. **เพิ่มคนร่วมทริปด้วยชื่อไม่ได้** (L1, D1) — ทั้ง 2 คนติด หารเงินไม่ได้เลย ซึ่งเป็นหัวใจของแอป
2. **สรุป "ไม่มีใครต้องโอน" / การ์ด "฿0 เคลียร์แล้ว" ทั้งที่จ่ายคนเดียว** (D11, L17) — ตัวเลขเงินทำให้ไม่ไว้ใจแอป
3. **โน้ตที่บันทึกหายจากจอ** (D4) — ผู้ใช้รู้สึกว่าข้อมูลหาย
4. **แก้ข้อมูลโรงแรม/สถานที่ไม่ได้** (D8) — ทำผิดแล้วแก้ไม่ได้ ถึงขั้นยอมแพ้

### P1 — ทำได้แต่ติดหนัก และทั้ง 2 คนเจอ
5. **โรงแรมไม่มีช่องที่ควรมี** — เช็คอิน/เช็คเอาท์/จำนวนคืน/ราคา/เลขจอง/ที่อยู่ (L7, D3)
6. **ไม่มีภาพรวม "คืนไหนนอนที่ไหน" / หน้ารวมทั้งทริป** (L13, L12, D13)
7. **ขั้นตอนเพิ่มโรงแรมยาวเกินไป** — ~10 คลิก, สร้างแล้วต้องไปจัดวันอีกรอบ, ใส่เมืองซ้ำ (L8, D7, D10)
8. **กดแล้วไม่มี feedback** — ควรมีตัวบอกว่ากำลังโหลด (L2, D14)
   - หมายเหตุ: ป้าย "Rendering…" และความช้าอาจมาจาก dev mode ควรเช็คบน production build ก่อนสรุป

### P2 — ค่าเริ่มต้นที่ทำให้พลาดง่าย
9. ค่าเริ่มต้นผิด/เสี่ยง: วัน 1 ติ๊กไว้ตอนลงแผน (L11, D10), เมืองติดค่าเดิม (L9), ประเภทเป็น "ที่กิน" (D6), ทริปถูกตั้งเป็น 4 วัน (D2)
10. ปุ่มบันทึกสีเทาโดยไม่บอกเหตุผล (D5)
11. "เส้นทางเมือง" ว่างและซ่อนอยู่ ไม่ดึงจากโรงแรม/รถไฟ และไม่โชว์ในหน้าแผน (L14)
12. ค่าใช้จ่ายไม่ผูกกับโรงแรม และวันที่ไม่ตรง (D12)
13. ไม่รองรับเงินสกุลอื่น เช่นเยน (L16) — สำคัญถ้าจะรองรับทริปต่างประเทศ

### P3 — ชื่อปุ่ม คำศัพท์ และงานเก็บรายละเอียด
14. ชื่อไม่ตรงความหมาย: "เที่ยวบิน/ตั๋ว" ควรเป็น "การเดินทาง" (L4), "สรุป" ควรเป็น "สรุปเงิน" (L15)
15. คำไม่คุ้น: ลงแผน, ย่าน, tag, ลิสต์, ยังไม่จัดวัน, เคลียร์, เศษสตางค์ (L18, D15)
16. ลิงก์เชิญไม่บอกว่าต้องรออนุมัติ, คำว่า "รีเซ็ตลิงก์" น่ากลัว (L3)
17. ปุ่มลบสีแดงอยู่ใกล้ (D9), ปุ่ม "เพิ่ม" เมืองขยับ (L10)
18. ไม่เตือนไฟลต์ขากลับ (L5), เรือไปกลับท่าเดิมถูกบังคับใส่ปลายทาง (L6)
