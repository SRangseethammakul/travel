## สรุป

- **Build:** `aea19d0` + การแก้ที่ยังไม่ commit ใน working tree (Edit Trip `/trips/[tripId]/edit`, `summary-view.ts`, `settle-view.ts` ฯลฯ ตาม `git status` ตอนเริ่ม)
- **สภาพแวดล้อม:** ตอนเริ่ม Docker ไม่ได้รัน และ :3000 ถูก container `erp-backend` ของอีกโปรเจกต์จองไว้ → team-lead ขออนุญาตผู้ใช้แล้วหยุด `erp-backend` · เปิด Docker + `docker compose up -d --build mongo backend` (:4000) และ `npm run dev` ใน `frontend/` (:3000) — **ปล่อยรันไว้ทั้งคู่** · **ไม่ได้ seed** (ข้อมูลเดิมมีครบ และ qa-ipad ใช้ DB เดียวกัน)
- **โฮสต์:** ทดสอบที่ `http://qa-m.localhost:3000` (loopback เดียวกัน) เพื่อแยก cookie `mock-user` ออกจาก qa-ipad ที่ใช้ `127.0.0.1` / `localhost` ในโปรไฟล์ Chrome เดียวกัน (เจอว่า cookie ชนกันจริง: เปิด 127.0.0.1 แล้วขึ้นเป็น "QA-T-Oat" ของอีก agent)
- **ความกว้าง:** Chrome ย่อหน้าต่างไม่ได้ (`innerWidth` 1512 แม้สั่ง 390×844) จึงใช้ **iframe ต้นทางเดียวกัน** ที่ viewport จริง `innerWidth × innerHeight` = **390×844** (ตรวจทุกหน้าด้วยสคริปต์), แล้ว 360×740 และ 844×390 (แนวนอน) · ซ่อนแถบสลับผู้ใช้ (dev) ตอนตรวจ layout เพราะไม่มีใน production
- **User และสิทธิ์ (สร้างใหม่ใน DB สำหรับรอบนี้):** `qa-m-owner` (ผู้จัดทริป), `qa-m-editor` (Claim "QA-M-Editor" → editor), `qa-m-viewer` (Claim "QA-M-Viewer" → viewer), `qa-m-outsider` (คนนอกทริป), ไม่ล็อกอิน (curl) · Unclaimed Member "นายสมชายผู้มีชื่อยาวมากเป็นพิเศษจริงๆ" (editor)

## ไม่ได้ทดสอบ

- **LINE / Google login จริง และ logout ทุกอุปกรณ์ด้วย session cookie:** ไม่มี credentials (`provider_disabled`)
- **signed URL หมดอายุ (5 นาที), ลิงก์เชิญหมดอายุ/รีเซ็ต, backend หยุด, เน็ตช้า, ไฟล์ 10 MB / HEIC, สองแท็บแก้ Expense เดียวกัน, Checklist, ManageTags, ทริปหลายเมือง, Activity โหลดเพิ่ม** — เวลาไม่พอ (หยุดกลางรอบเพราะ usage limit) จัดลำดับให้ flow เงิน/สิทธิ์ก่อน
