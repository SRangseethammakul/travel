จดบั๊กแล้วทดสอบต่อจนจบ ถ้าบั๊กทำให้ไปขั้นถัดไปไม่ได้ ให้เลี่ยงโดยไม่แก้โค้ด (เช่นเรียก API ตรงด้วย curl) และระบุในรายงานว่าเลี่ยงอย่างไร จบแล้วสรุปว่าผ่านหรือไม่ผ่าน (go / no-go) ข้อใน "ค้างไว้แก้ทีเดียว" ของ `connect-api.md` ให้จดผลเฉพาะข้อที่อยู่บนเส้นทางนี้
