# Travel Planner — สรุปการออกแบบ

อัปเดต 11 พ.ย. 2569 · เอกสารต้นฉบับ: https://claude.ai/artifact/Jj2mef3gpjSieQ43LZLLgz

## ภาพรวม

Travel Planner คือ web app แบบมือถือเป็นหลัก สำหรับเที่ยวเป็นกลุ่ม ครอบคลุมตั้งแต่ list สถานที่ วางแผนรายวัน จดค่าใช้จ่าย จนถึงหารเงินและโอนคืนกัน แบบมี 22 หน้าจอขนาด 390×844 (mockup วาดที่ 390px แต่แอปจริงยืดได้ถึง 640px ให้ใช้ได้ทั้งมือถือ 320px ขึ้นไปและแท็บเล็ต)

ข้อมูลตัวอย่างในทุกหน้าคือทริป "โตเกียวหน้าหนาว" ของสมาชิก 4 คน (Act, Mint, Beam, Ploy) วันที่ 12–15 ธ.ค. 2569 ใช้จ่ายรวม ฿30,350 ตัวเลขทุกหน้าคำนวณให้ตรงกัน

หลักการที่ตัดสินใจแล้ว:

- **เงินบาทเป็นหลัก:** ยอดรวม ยอดสุทธิ และการโอนคืนเป็นบาททั้งหมด สกุลต่างประเทศไว้เวอร์ชันถัดไป
- **ลิงก์ Google Maps เก็บไว้เปิดอย่างเดียว:** ระบบไม่ดึงข้อมูลจากลิงก์ ไม่เรียก API แผนที่
- **สถานที่เป็นคลังกลางของทริป:** แยกจากแผน ที่เดียวลงแผนได้หลายวัน เช่น โรงแรมเดิมทุกคืน
- **จัดสถานที่เป็นเมือง › ย่าน + tag:** ผู้ใช้เลือกเมืองและย่านเอง tag ใส่ได้หลายอัน การจัดกลุ่ม tag เป็นตัวเลือกเสริม
- **โอนคืนคิดจากยอดสุทธิทั้งทริป:** ไม่โอนแยกทีละรายการ ระบบคำนวณให้โอนน้อยครั้งที่สุด
- **เข้าสู่ระบบด้วย LINE หรือ Google**
- **มือถือก่อน:** หน้าจอ iPad และคอมยังไม่ได้ออกแบบ

## แผนผังหน้าจอ

```
ก่อนเข้าทริป:  10 เข้าร่วมทริป → 19 เข้าสู่ระบบ ─┐
               9 ทริปของฉัน ──────────────────┤
               6 สร้างทริป ───────────────────┤
                                              ▼
                                  1 ทริป (หน้าหลัก)
          ├─ 20 สมาชิก   ├─ 22 เช็คลิสต์   ├─ 21 แจ้งเตือน
          └─ เมนูล่าง 5 แท็บ
               ├─ 7 แผนรายวัน → 13 เพิ่มกิจกรรม, 18 การเดินทาง
               ├─ 2 สถานที่   → 8 เพิ่มสถานที่, 17 จัดการ tag
               ├─ 3 ค่าใช้จ่าย → 4 เพิ่ม + หารเงิน, 11 รายละเอียด
               └─ 5 สรุป      → 12 โอนเงินคืน
```

หน้า 14–16 คือหน้าเดียวกันเมื่อทริปมีหลายเมือง (ตัวอย่างญี่ปุ่น)

## ทริป สมาชิก และบัญชี

ผู้จัดทริปสร้างทริป แล้วส่งลิงก์ให้เพื่อน เพื่อนเลือกว่าตัวเองคือใครในรายชื่อ แล้วเข้าระบบด้วย LINE หรือ Google ค่าใช้จ่ายที่บันทึกไว้ในชื่อนั้นจะย้ายมาอยู่ในบัญชีของเขา

| หน้า | ทำอะไรได้ |
| --- | --- |
| 9 · ทริปของฉัน | แท็บกำลังจะไป / ผ่านมาแล้ว การ์ดทริปบอกยอดคงเหลือของฉัน (ได้คืน/ค้างจ่าย) ปุ่มสร้างทริปและเข้าร่วมด้วยลิงก์ |
| 6 · สร้างทริปใหม่ | ชื่อ ปลายทาง วันไป-กลับ งบประมาณ สีหน้าปก เพิ่ม/ลบสมาชิก และอัปโหลดเอกสาร (PDF/รูป) ที่ตั้งชื่อเองได้ มีชื่อสำเร็จรูปให้กด เช่น ใบจองโรงแรม ใบจองรถ |
| 1 · ทริป | หน้าหลักของทริป: นับถอยหลัง สมาชิก รายละเอียดการเดินทาง งบที่ใช้ไป การ์ดเช็คลิสต์ แผนรายวัน กระดิ่งแจ้งเตือน |
| 10 · เข้าร่วมทริป | ดูตัวอย่างทริป เลือกชื่อตัวเองที่เพื่อนเพิ่มไว้ (บอกจำนวนรายการและยอดที่ผูกอยู่) หรือเพิ่มตัวเองเป็นสมาชิกใหม่ |
| 19 · เข้าสู่ระบบ | LINE หรือ Google ใช้แค่ชื่อ อีเมล และรูปโปรไฟล์ ถ้ามาจากลิงก์เชิญ จะบอกชื่อทริปและชื่อที่เลือก |
| 20 · สมาชิกและสิทธิ์ | เปลี่ยนสิทธิ์ นำสมาชิกออก ตั้งลิงก์เชิญหมดอายุ (1 วัน / 7 วัน / ไม่หมด) ต้องอนุมัติก่อนเข้า และรีเซ็ตลิงก์ |

สิทธิ์มี 3 ระดับ:

| สิทธิ์ | ทำได้ |
| --- | --- |
| ผู้จัดทริป | แก้ได้ทุกอย่าง จัดการสมาชิกและลิงก์เชิญ ลบทริป |
| แก้ไขได้ | เพิ่มสถานที่ แผน และค่าใช้จ่าย แก้หรือลบได้เฉพาะค่าใช้จ่ายที่ตัวเองสร้าง |
| ดูอย่างเดียว | ดูแผนและยอดของตัวเอง แจ้งโอนเงินได้ |

สิทธิ์ต้องตรวจที่ backend ทุก endpoint ที่แก้หรือลบ การซ่อนปุ่มในหน้าจอเป็นแค่ UX ปุ่ม LINE/Google ใน mockup เป็นแบบกลาง ตอนทำจริงต้องใช้ปุ่มตามแนวทางของแต่ละเจ้า

## สถานที่และแผน

หน้าสถานที่คือรายการที่อยากไป ส่วนหน้าแผนคือไปวันไหน กี่โมง ตัวอย่างมี 12 สถานที่ใน Tokyo แบ่ง 5 ย่าน ยังไม่จัดวัน 3 ที่

**สถานที่ (หน้า 2, 8, 17)**

- **จัดกลุ่มตามย่านหรือตามประเภท:** หัวกลุ่มบอกจำนวน เช่น "Shinjuku · 4 ที่ · ลงแผน 3"
- **ตัวกรอง:** tag (กดได้หลายอัน) และสวิตช์ "ยังไม่จัดวัน"
- **แท็บเมือง:** แสดงเฉพาะเมื่อทริปมีมากกว่า 1 เมือง (ดูตัวอย่างทริปญี่ปุ่นหลายเมือง หน้า 14–16)
- **ฟอร์มเพิ่มสถานที่:** ชื่อ, ลิงก์ Google Maps (ไม่บังคับ), ประเภท, เมือง, ย่าน, tag และโน้ต บันทึกลงลิสต์ได้เลยโดยไม่ต้องเลือกวัน
- **Tag:** มีช่องเดียว พิมพ์ใหม่หรือกดจาก tag ที่เคยใช้ คนที่อยากจัดละเอียดย้าย tag เข้ากลุ่ม (เช่น อาหาร) ได้ในหน้าจัดการ tag

**แผนรายวัน (หน้า 7, 13, 18)**

- **Timeline ต่อวัน:** สลับวันที่ 1–4 ได้ หัววันบอกย่านที่ไป ด้านล่างมีกล่อง "ยังไม่จัดวัน" กดเพิ่มเข้าวันที่เปิดอยู่
- **เพิ่มกิจกรรมจากคลัง:** ที่อยู่ย่านเดียวกับแผนของวันนั้นขึ้นก่อน เลือกเวลา และติ๊กได้หลายวันพร้อมกัน
- **การเดินทางมี 2 แบบ:**

| แบบ | เช่น | ใส่อะไร | อยู่ตรงไหน |
| --- | --- | --- | --- |
| ช่วงเดินทางระหว่างจุด | เดินจากเซ็นโซจิไป Skytree | วิธีเดินทาง (เดิน/รถไฟ/รถบัส/แท็กซี่/รถเช่า) นาที โน้ต | ปุ่มเล็กคั่นระหว่างรายการใน Planner |
| การเดินทางที่จองไว้ | เที่ยวบิน BKK → HND | ประเภท ต้นทาง→ปลายทาง วันเวลาออก/ถึง เลขที่จอง แนบเอกสารจากทริป ผูกค่าใช้จ่าย | การ์ดสีม่วงใน timeline |

ทริปหลายเมืองใส่เส้นทางเมืองได้ (ไม่บังคับ) เช่น Tokyo วัน 1–4 → Kyoto วัน 5–6 → Osaka วัน 7–9 เพื่อให้ Planner แสดงที่ของเมืองนั้นก่อน

## ค่าใช้จ่ายและการหาร

ทุกคนจดค่าใช้จ่ายที่ตัวเองสำรองจ่าย แล้วระบบรวมเป็นยอดสุทธิต่อคน ในตัวอย่าง Act สำรองจ่ายที่พัก ฿22,000 จึงได้คืน ฿14,050 จากอีก 3 คน

**เพิ่มค่าใช้จ่าย (หน้า 4)** ใส่จำนวนเงิน รายการ หมวด (ที่พัก/เดินทาง/อาหาร/ตั๋ว/อื่นๆ) คนจ่าย ช่องทางชำระ และคนที่ร่วมหาร ปุ่มบันทึกจะกดได้เมื่อแบ่งยอดครบพอดี

| วิธีหาร | ใช้เมื่อ | การทำงาน |
| --- | --- | --- |
| เท่ากัน | ทุกคนกินหรือใช้เท่ากัน | หารตามจำนวนคนที่ติ๊ก เศษสตางค์รวมไว้กับผู้จ่าย |
| ระบุจำนวน | บางคนไม่ดื่มหรือสั่งน้อย | ใส่ยอดของแต่ละคน แถบสถานะบอกยอดที่เหลือหรือเกิน มีปุ่มเกลี่ยส่วนที่เหลือ |
| ตามสัดส่วน | ห้องใหญ่กับห้องเล็ก | ปุ่ม − / + นับเป็นส่วน ระบบคำนวณยอดให้ |

ช่องทางชำระมี เงินสด, โอน/พร้อมเพย์ (แนบสลิปได้), บัตรเครดิต/เดบิต (ใส่เลขท้าย 4 หลักได้) และ e-Wallet

**สรุปและโอนคืน (หน้า 3, 5, 11, 12)**

- หน้ารายการจัดกลุ่มตามวัน กดรายการเพื่อดูรายละเอียด แก้ หรือลบ (มีหน้าต่างยืนยันก่อนลบ)
- หน้าสรุปแสดงสัดส่วนตามหมวด ยอดของแต่ละคน (กดดูที่มาได้) และ "ใครต้องโอนให้ใคร"
- หน้าโอนเงินมี 3 สถานะ: รอโอน → รอยืนยัน (ผู้โอนแนบสลิป) → เสร็จสิ้น (ผู้รับกดยืนยัน) มี QR พร้อมเพย์ของผู้รับ

| สมาชิก | จ่ายไปแล้ว | ส่วนที่ต้องจ่าย | สุทธิ | สถานะการโอนให้ Act |
| --- | --- | --- | --- | --- |
| Act | ฿22,000 | ฿7,950 | +฿14,050 | — |
| Mint | ฿4,500 | ฿7,600 | −฿3,100 | เคลียร์แล้ว |
| Beam | ฿1,050 | ฿6,850 | −฿5,800 | รอยืนยัน |
| Ploy | ฿2,800 | ฿7,950 | −฿5,150 | ยังไม่โอน |

## เช็คลิสต์และความเคลื่อนไหว

เช็คลิสต์แยกเป็นกลุ่มกับส่วนตัว มีรายการตั้งต้นมาให้ และหน้าความเคลื่อนไหวบอกทุกคนว่าใครเพิ่มหรือแก้อะไร

| | กลุ่ม | ส่วนตัว |
| --- | --- | --- |
| ใครเห็น | ทุกคนในทริป ติ๊กได้ทุกคน | เจ้าของคนเดียว |
| รายการตั้งต้น | การจอง (ตั๋วเครื่องบิน ที่พัก ประกัน ตั๋วกิจกรรม) และของใช้ร่วมกัน (eSIM ปลั๊กแปลงไฟ ยาสามัญ) | เอกสาร เสื้อผ้า ของใช้ |
| คนรับผิดชอบ | กดเปลี่ยนคนได้ ติ๊กแล้วบอก "เสร็จโดย ..." | — |
| เพิ่มเอง | พิมพ์เอง หรือกดจากรายการแนะนำ (เช่น แลกเงิน ร่มพับ) | พิมพ์เอง หรือกดจากรายการแนะนำ |

**ความเคลื่อนไหว (หน้า 21)** เข้าจากกระดิ่งในหน้าทริป จัดกลุ่มเป็นวันนี้/เมื่อวาน กรองตามค่าใช้จ่าย การโอน แผนและสถานที่ หรือสมาชิก รายการที่ต้องทำต่อมีปุ่มในตัว เช่น "ตรวจและยืนยัน" เมื่อมีคนแจ้งโอน ผู้ใช้เลือกได้ว่าจะรับแจ้งเตือนบนมือถือเรื่องไหน (ค่าใช้จ่ายที่ตัวเองต้องจ่ายด้วย การโอนเงิน แผนเปลี่ยน สมาชิกเข้าร่วม เตือนก่อนเดินทาง 1 วัน)

## ระบบภาพ

พื้นเทาเย็น ตัวอักษรน้ำเงินเข้ม และสีหลัก teal เพียงสีเดียวสำหรับปุ่มและสถานะที่เลือกอยู่ สีอื่นใช้บอกประเภทและสถานะ

| หน้าที่ | สี | ใช้กับ |

| พื้นหลัง | #F3F5F7 | พื้นหน้าจอ การ์ดเป็น #FFFFFF |

| ตัวอักษรรอง | #5B6B78 | คำอธิบาย เมนูที่ไม่ได้เลือก |
| สีหลัก | #0B7A6A | ปุ่มหลัก สถานะเลือก ยอดได้คืน พื้นอ่อน #E3F2EF |
| ค้างจ่าย / ลบ | #B23A2E | ยอดติดลบ ปุ่มลบ |
| ต้องทำต่อ | #8A4A0C บน #FCEBDD | ยังไม่จัดวัน รอยืนยัน ยอดยังแบ่งไม่ครบ |

- **ฟอนต์:** Prompt (หัวข้อและตัวเลข) กับ IBM Plex Sans Thai (เนื้อความ) จาก Google Fonts
- **ขนาด:** หัวหน้า 24px · หัวส่วน 17px · เนื้อความ 15px · คำอธิบาย 12–13px
- **ส่วนประกอบที่ใช้ซ้ำ:** การ์ดมุมมน 18–24px, chip/เม็ดกรอง, ตัวเลือกแบบแบ่งช่อง (segmented), แผ่นที่เลื่อนขึ้นจากด้านล่าง, ปุ่มลอย (FAB), แถบเมนูล่าง 5 แท็บ (ทริป · แผน · สถานที่ · ค่าใช้จ่าย · สรุป)
- **การเข้าถึง:** ปุ่มสูงอย่างน้อย 44px, ความต่างสีตัวอักษรอย่างน้อย 4.5:1, ใช้ button/link/input จริงพร้อม aria-label บนปุ่มไอคอน, ไม่ใช้ emoji

```ts
Tag       { ownerId, name, group?: string, color }      // ใช้ได้ทุกทริปของเจ้าของ
PlanItem  =
  | { kind: 'place',   tripId, day, time, placeId, note, travelToNext?: { mode, minutes?, note? } }
  | { kind: 'transit', tripId, mode, fromText, toText, departAt, arriveAt, bookingRef?, docIds: [], expenseId? }

Expense   { tripId, title, category, payerId, method, amount, currency: 'THB', baseAmount,
            splitMode: 'equal' | 'amount' | 'shares',
            shares: [{ memberId, amount?, weight? }], slipDocId?, createdBy }
Settlement{ tripId, fromId, toId, amount, status: 'pending' | 'sent' | 'confirmed', slipDocId? }
PersonalExpense { tripId, ownerId, title, category, amount, currency: 'THB', baseAmount, method, note?, date }  // ส่วนตัว ไม่มี payer/shares

ChecklistItem { tripId, scope: 'group' | 'personal', ownerId?, text, category, assigneeId?, doneBy?, fromTemplate }
Activity  { tripId, actorId, type, refId, text, createdAt }
```

- ยอดสุทธิคำนวณจาก Expense ทุกครั้ง ไม่เก็บซ้ำ ส่วน Settlement เก็บเฉพาะการโอนที่เกิดขึ้นจริง
- รายการเช็คลิสต์ `personal` ต้องกรองด้วย `ownerId` ที่ backend เสมอ
- PersonalExpense (ค่าใช้จ่ายส่วนตัว) เห็นได้เฉพาะเจ้าของ กรองด้วย `ownerId` ที่ backend เสมอ ทุก role เพิ่ม/แก้/ลบของตัวเองได้ หมวดเพิ่ม `shopping` (ช็อปปิ้ง) ไม่นับในยอดรวมทริป ยอดสุทธิ การโอน หรือสรุป และไม่ลง Activity index `{ tripId, ownerId, date }`
- index หลัก: `{ tripId, area }` และ `tagIds` (multikey) ของ Place, `{ tripId, day, time }` ของ PlanItem

- [ ] หน้าทริปใหม่ตอนยังไม่มีข้อมูล (empty state) และ onboarding ผู้ใช้ใหม่
